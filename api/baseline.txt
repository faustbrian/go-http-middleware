package middleware // import "github.com/faustbrian/go-http-middleware/v2"

Package middleware composes explicit net/http middleware without a registry.

Start with New or Described, then resolve Handler around the terminal. Layers
are listed in request execution order and response calls unwind in reverse.
Construction snapshots metadata, not decorator/handler closures; those remain
caller-owned. It owns no server, router, authentication, signing, retry,
replay ledger or shutdown. Callback cancellation is cooperative through request
context.

CONSTANTS

const MaxChainDepth = 256
    MaxChainDepth is the New/Described input-count ceiling. Append/Prepend and
    Handler do not re-admit that count; it is not a universal serving-depth
    bound.

TYPES

type Chain struct {
	// Has unexported fields.
}
    Chain is an immutable ordered sequence of middleware descriptors.

func Described(descriptors ...Descriptor) (Chain, error)
    Described snapshots descriptors and validates count, nil layers, names
    and ordering. Repeated nonempty names require every occurrence to permit
    duplicates; absent ordering targets impose no constraint and layers are
    never reordered.

func New(middleware ...Middleware) (Chain, error)
    New constructs a chain from unnamed middleware.

func (c Chain) Append(descriptor Descriptor) Chain
    Append returns a metadata copy with descriptor last, without
    validation/count admission. Use Described/Concat when the New/Described
    count ceiling is required.

func (c Chain) Concat(suffix Chain) (Chain, error)
    Concat returns a validated chain containing c followed by suffix.

func (c Chain) Descriptors() []Descriptor
    Descriptors returns an independent snapshot in request execution order.

func (c Chain) Handler(terminal http.Handler) (http.Handler, error)
    Handler validates descriptors and resolves decorators from last to first.
    Nil terminal/results return ConstructionError; decorator panics propagate.
    Resolution effects are not rolled back on failure. The zero chain returns
    the terminal. Existing limitation: appended/prepended depth is not rechecked
    here. Callers own terminal/decorator lifetimes and concurrent invocation
    safety.

func (c Chain) Prepend(descriptor Descriptor) Chain
    Prepend returns a new chain with descriptor first. Invalid input is retained
    for descriptor validation by Concat or Handler. No count admission is done
    here; use Described/Concat to enforce MaxChainDepth before resolving an
    extended chain.

package admission // import "github.com/faustbrian/go-http-middleware/v2/admission"

Package admission bounds local in-flight requests without implementing a
distributed rate algorithm. New returns a factory whose uses share semaphore
state. The caller owns the shutdown signal; middleware owns bounded wait timers
and permit release, not active-handler cancellation, draining or server closure.

VARIABLES

var ErrInvalidPolicy = errors.New("admission: invalid policy")
    ErrInvalidPolicy identifies invalid admission policy configuration.


FUNCTIONS

func New(policy Policy) (func(http.Handler) http.Handler, error)
    New constructs semaphore admission. Channel wait order is not a contractual
    fairness guarantee; queues are bounded and allocate no waiter goroutine.
    Saturation or shutdown emits 503, canceled admission 408. Acquired permits
    survive until downstream return/panic; shutdown does not revoke them
    or join active handlers. A queued acquisition rechecks cancellation,
    but shutdown/acquisition arbitration is not a guarantee that no handler can
    start concurrently with signal closure.


TYPES

	// Field names the invalid policy field without echoing its configured value.
	Field string
}
    ConfigError reports an invalid admission policy field.

func (e *ConfigError) Error() string
    Error formats the policy-field diagnostic; constructors use fixed field
    labels.

func (e *ConfigError) Unwrap() error
    Unwrap exposes ErrInvalidPolicy for errors.Is.

type Policy struct {
	// MaxInFlight is required in [1,1000000]; capacity is shared by the returned factory.
	// MaxWaiters bounds queued callers in [0,1000000]; zero disables waiting.
	MaxInFlight, MaxWaiters int
	// Wait bounds queue residence up to one minute, not handler time; zero refuses saturation.
	Wait time.Duration
	// RetryAfterSeconds is a nonnegative refusal hint; zero omits the header.
	RetryAfterSeconds int
	// Shutdown is caller-owned; close to persistently refuse/wake waiters. It does not cancel or join admitted handlers.
	Shutdown <-chan struct{}
}
    Policy configures bounded local request admission. Wait is capped at one
    minute.

package bodylimit // import "github.com/faustbrian/go-http-middleware/v2/bodylimit"

decoding. Install New before any body reader; previously consumed bytes cannot
be counted. It mutates the request Body/Close fields and delegates body closure
to the server/caller. It owns no decompression, multipart parser or read
deadline.

package compress // import "github.com/faustbrian/go-http-middleware/v2/compress"

Package compress performs bounded gzip content-coding negotiation. Sensitive
dynamic responses should opt out by setting Cache-Control: no-transform.
New uses selected RFC9110/9111 field policies, not decompression or message
signing. It buffers payload then may stream; header/trailer storage and total
heap/time are not capped by MaxBuffer. Buffered writers withhold optional
streaming/takeover interfaces; downstream owns request and callback lifetimes.

VARIABLES

var ErrInvalidPolicy = errors.New("compress: invalid policy")
    ErrInvalidPolicy identifies invalid compression policy configuration.


FUNCTIONS

func New(policy Policy) (func(http.Handler) http.Handler, error)
    New constructs gzip middleware. Responses are buffered up to MaxBuffer so
    eligibility can be decided before commitment. Larger eligible responses
    continue as gzip streams; other responses spill as identity. Existing wire
    limitation: an ineligible response can use identity even when negotiation
    gave identity q=0. The initial 406 only covers no acceptable supported
    coding. Final buffered copy/encoder-close errors cannot be returned by
    ServeHTTP and are discarded; payload bytes are not guaranteed transport
    delivery. Panics propagate after closing an active encoder, without
    middleware cancellation.

package content // import "github.com/faustbrian/go-http-middleware/v2/content"

package cors // import "github.com/faustbrian/go-http-middleware/v2/cors"

Package cors implements the server-facing portion of the Fetch CORS protocol
under the repository-pinned Fetch authority, not a full browser implementation.
Start with New; configured lists are copied, dynamic origin callbacks borrowed.
CORS controls browser visibility, not authentication, request execution or CSRF
protection; ordinary denied origins still reach next.

VARIABLES

var ErrInvalidPolicy = errors.New("cors: invalid policy")
    ErrInvalidPolicy identifies invalid CORS policy configuration.


FUNCTIONS

func New(policy Policy) (func(http.Handler) http.Handler, error)
    New canonicalizes configured origins and validates wildcard/credential
    policy. Malformed/denied preflights short circuit; ordinary requests with

    opaque null origin; without wildcard, an exact entry or approving dynamic
    callback can admit null. Dynamic callback errors deny and panics propagate;
    callbacks run synchronously with advisory context, without imposed latency
    or concurrency safety. No request body is read.

package deadline // import "github.com/faustbrian/go-http-middleware/v2/deadline"

Package deadline offers synchronous context deadlines with New and bounded
non-streaming response timeouts with NewTimeout. Only the latter starts handler
workers; timed-out workers retain capacity until cooperative return. Neither
owns server read/write/idle, upstream, shutdown or process limits.

VARIABLES

var (
	// ErrHandlerTimeout is returned to late writes after the response timeout.
	ErrHandlerTimeout = errors.New("deadline: handler timeout")
	// ErrResponseTooLarge identifies output above the configured buffer bound.
	ErrResponseTooLarge = errors.New("deadline: response too large")
)
var ErrInvalidPolicy = errors.New("deadline: invalid policy")
    ErrInvalidPolicy identifies invalid deadline policy configuration.


FUNCTIONS

func New(policy Policy) (func(http.Handler) http.Handler, error)
    New constructs synchronous context-deadline middleware. A shorter parent
    deadline is preserved; cancellation is deferred until downstream returns.
    The request clone shares Body and Header with its parent. No timeout
    response, goroutine, writer buffer or forced interruption is introduced;
    panics propagate.

func NewTimeout(policy TimeoutPolicy) (func(http.Handler) http.Handler, error)
    NewTimeout constructs bounded buffered timeout middleware. The wrapped
    writer intentionally exposes no streaming, hijacking, push, or full-duplex
    capability because those operations are incompatible with response replay.
    Each admitted request starts one worker, retaining its slot until the
    handler returns even after timeout. There is no Close/drain/join; handlers
    must stop using request resources cooperatively. Timely panics reappear on
    the serving goroutine; a panic after timeout is recovered in the worker
    but not reported. MaxResponseBytes bounds payload only. Header() exposes a
    caller-owned mutable map, not synchronized arbitrary concurrent mutation;
    late payload writes fail, not header-map writes. Cancellation selects the
    error path but cannot impose a transport write deadline or preempt blocked
    informational-header forwarding.

    unbounded middleware-owned goroutine growth.

type Event struct {
	// Method is a known HTTP method or OTHER.
	Method string
	// Route is caller-selected metadata truncated to 128 bytes; no privacy/cardinality sanitization is applied.
	Route string
	// Status is recorded final status or 200 when absent; informational responses alone do not commit.
	Status int
	// Bytes counts successful writer payload bytes, not wire framing or guaranteed delivery.
	Bytes int64
	// Duration uses the injected clock and is clamped to zero when negative.
	Duration time.Duration
	// Proto is a known HTTP version or OTHER.
	Proto string
	// Outcome gives panic precedence over cancellation, then status classification.
	Outcome Outcome
	// ClientClass is caller-selected metadata truncated to 64 bytes, potentially splitting UTF-8.
	ClientClass string
}
    Event does not automatically collect paths, queries, headers, payloads,
    identities or errors. Caller-supplied Route/ClientClass can nevertheless
    leak them; byte truncation is neither sanitization nor bounded cardinality.
    Method and Proto use fixed known values plus OTHER.

type Outcome string
    Outcome is a bounded completion classification.

const (
	// Success classifies responses below 400.
	Success Outcome = "success"
	// ClientError classifies responses from 400 through 499.
	ClientError Outcome = "client_error"
	// ServerError classifies responses at or above 500.
	ServerError Outcome = "server_error"
	// Canceled classifies requests whose context was canceled.
	Canceled Outcome = "canceled"
	// Panicked classifies handlers that propagated a panic.
	Panicked Outcome = "panicked"
)
type Policy struct {
	// Observer is required borrowed synchronous caller code; receives the completion request context, possibly canceled.
	Observer func(context.Context, Event)
	// Route is a fallback classification extractor after downstream completion; panic yields empty metadata.
	Route func(*http.Request) string
